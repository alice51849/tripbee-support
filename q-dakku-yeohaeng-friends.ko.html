다꾸 여행 다이어리, 친구랑 같이 쓰기

우정 여행·커플 여행이라면 다꾸도 같이 하고 싶죠. TripBee Cute에서 일러스트 여행 책자 한 권을 친구와 함께 채우고, 쓴 돈은 더치페이로 정산하고, 앱이 없는 사람에게는 웹 책자로 보여 주는 방법을 앱 설명에 있는 기능만으로 정리했어요.

  • 함께 꾸미기
  • 더치페이 정산
  • 웹 책자로 공유
  • 구입 없이 쓰는 기능 / Cute Pass 기능
  • 자주 묻는 질문

1. 한 권을 같이 꾸미기

  • 표지 고르기: 도시, 랜드마크, 계절, 여행 분위기를 담은 일러스트 표지 중에서 골라요. 내 사진을 표지로 쓸 수도 있어요(Cute Pass).
  • 하루 일정 다꾸: 날마다 이름을 붙이고 스티커를 달고, 끝난 일정은 완료 체크해요. 순서도 바꿀 수 있어요.
  • 날짜별 색상: 날짜마다 색이 달라 한눈에 구분되고, 날짜 필터로 그날 일정만 볼 수 있어요.
  • 추억 붙이기: 사진, 티켓, 메모를 해당 일정 바로 옆에 보관해요.
  • 같이 편집: iCloud로 친구를 초대하면 같은 책자를 함께 편집하고 변경 사항이 서로의 기기에 동기화돼요. 친구도 TripBee Cute가 있어야 해요(친구와 함께 계획하기는 Cute Pass 기능).

2. 쓴 돈은 더치페이로

동행과 쓴 경비를 일정에 바로 적어 두면 돼요. 여행마다 누가 냈는지 기록하고 똑같이 나누거나 금액을 각자 입력할 수 있어요. 정산하면 누가 누구에게 보내면 되는지 한 번에 계산해 주고, 다른 통화는 실시간 환율로 환산해요. 더치페이는 구입하지 않아도 쓸 수 있어요.

3. 앱이 없는 사람에게는 웹 책자로

웹 책자로 공유하면 웹 파일 하나로 어떤 브라우저나 메신저에서도 열리고, 오프라인에서도 볼 수 있어요. 출발 디데이도 계속 줄어들어요. 앱이 없는 일행에게도 웹 책자로 한 권을 그대로 보여 줄 수 있어요.

4. 구입 없이 쓰는 기능 / Cute Pass 기능

구입하지 않아도책자 1권 보관, 표지 6종, CSV 가져오기, 웹 책자, 항공편, 하루 일정, 더치페이, 준비물 리스트, 위젯, Apple Watch 앱

계정 가입, 광고, 추적이 없어요. 책자는 기기에 저장되고, 동기화를 켰을 때만 내 개인 iCloud에 저장돼요.

앱이 없는 친구에게도 보여 줄 수 있나요?

웹 책자로 공유하면 어떤 브라우저나 메신저에서도 열리고 오프라인에서도 볼 수 있어요. 웹 책자는 구입하지 않아도 쓸 수 있는 기능이에요.

더치페이 정산도 되나요?

여행마다 누가 냈는지 기록하고 똑같이 나누거나 금액을 각자 입력할 수 있어요. 정산하면 누가 누구에게 보내면 되는지 계산해 주고, 다른 통화는 실시간 환율로 환산해요.

구입하지 않으면 무엇을 쓸 수 있나요?
